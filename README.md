# รายการงานของฉัน (Thai Todo App)

React + Vite + Tailwind CSS + lucide-react

## เริ่มใช้งาน

```bash
npm install
npm run dev      # เปิด dev server
npm run build    # build สำหรับ production (โฟลเดอร์ dist)
npm run preview  # ดูผลลัพธ์ที่ build แล้ว
```

ข้อมูลทั้งหมดเก็บใน React state เท่านั้น (ไม่ใช้ localStorage) รีเฟรชหน้าแล้วข้อมูลจะรีเซ็ต
